# Battle 战斗服务器

`Battle` 服务负责高实时性战斗逻辑与对局内同步计算，专注于低延迟、高频率、强一致性的战斗场景处理。将战斗逻辑与 `Game` 解耦，可以降低非战斗业务受大规模战斗计算影响的风险。

## 核心职责
- **帧同步与状态广播**：处理战斗输入、帧推进、状态校验与同步下发。
- **空间与碰撞计算**：支持技能范围、位移、碰撞、射线等战斗判定。
- **高频消息分发**：面向同屏玩家进行高频更新，适配低延迟通信场景。

## 与其他服务协作
- `Game`：发起进入对局、离开对局、战斗结算写回等业务联动。
- `Center`：在跨服或多节点场景下参与调度与分配。
- `Gateway`：负责客户端连接汇聚与消息路由，战斗服专注业务处理。
- `DB`：持久化结算结果、战斗统计、历史记录等数据。

## 典型流程
1. 玩家在 `Game` 或匹配系统中完成组队/匹配。
2. `Center` 或调度逻辑分配目标 `Battle` 节点。
3. 客户端战斗消息经 `Gateway` 路由到对应 `Battle`。
4. 战斗结束后，结果回传 `Game` 并落库到 `DB`。
5. 清理房间与临时战斗状态，释放节点资源。
