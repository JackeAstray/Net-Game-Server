# Gateway 网关服务器

`Gateway` 是本游戏架构中直面外部网络玩家的**第一道大门**，所有的异构外部长连接会汇总到这里。它承担了鉴权前缓冲、流量拆分解包、协议汇聚以及将其路由至内部子网服务器的作用。

## 核心职责
- **多协议侦听**: 目前 `Gateway` 能够使用 TCP 以及 WebSockets 等实例化进行连接挂靠，这意味着不同终端通过不同方式打进来在这里都能做到统一抽象合并。
- **拆解与封装**: 接收网络二进制流后，进行粘包/半包的处理计算。提取出基础协议的 `MsgId` 用以判断该消息到底是该给 `Login` 还是 `Game` 节点处理。
- **内部转发**: 和内部的服务之间保持着高利用率的长久连接，外部客户端发来的消息被剥离、校验后补加玩家自身的 `ClientSessionId` 再封包打给微服务集群的内部各个服务器模块。同时它也监听来源于内部比如 `Login` 或者 `Game` 等节点的下发请求，寻找对于原本 `ClientSessionId` 实例向用户真实长流吐信息。
- **防御和缓冲**: 可用于处理黑白名单、连接限流攻击防范等安全性需求。

## 适用场景
所有的客户端在连入游玩时都会唯一和当前这个服或该大区的某一个 `Gateway` 常量连接打交道，而根本不会关心身后的 `Game`、`Login` 和 `Battle` 节点如何变化。
