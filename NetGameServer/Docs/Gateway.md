# Gateway 网关服务器

`Gateway` 是外部客户端进入服务集群的统一入口，负责连接接入、协议解析、消息路由和回包转发。

## 核心职责
- **多协议接入**：统一监听并管理 TCP / UDP(KCP) / WebSocket 等连接。
- **收包与拆包**：处理长度帧、粘包/半包，提取 `MsgId` 与业务负载。
- **路由转发**：根据 `MsgId` 范围将请求转发到 `Login`、`Game`、`Center`、`Battle` 等服务。
- **会话映射**：维护 `ClientSessionId` 与连接实例关系，确保回包准确投递。
- **安全防护**：支持限流、黑白名单、异常连接清理等边界防护策略。

## 协议约束
- 客户端到网关：`[MsgId(4)][Payload]`（外层使用长度帧封包）。
- 网关到业务服：`[ClientSessionId(8)][MsgId(4)][Payload]`。
- 业务服回网关：`[ClientSessionId(8)][MsgId(4)][Payload]`。

## 设计原则
- 网关尽量保持无状态或弱状态，业务逻辑下沉到业务服。
- 协议统一优先，避免在网关内部保留多套兼容分支。
- 接入层扩容应以连接数与带宽压力为主要指标。
