# Gateway 服务器 (统一网关接入服务)

## 概述
Gateway（网关端）是所有连接到游戏服务器集群的客户端的第一道入口。无论客户端通过何种网络协议连接进来，它们都不直接与背后的逻辑服务器（Login、Game、Battle 等）发生底层套接字层面的往来，全部需要 Gateway 的转发。

## 核心设计要求
作为游戏服务器架构的最前端，稳定性和高并发支持是第一要素，网关中**绝对不能**编写任何与角色状态或场景玩法相关的直接业务逻辑。

## 核心职责

1. **多协议接入**
   - 通过 `Network` 模块，监听和接受外部进来的 TCP、UDP (KCP 封装)、WebSockets 的异构网络连接，将其统一抽象为 Session 会话管理。
   
2. **流量清洗与安全校验**
   - 包含连接限流防御；拒绝超过限制的心跳/发包频率操作。处理底层通信协议的封包、拆包、CRC校验处理、甚至数据的解密等。

3. **消息路由与动态分发 (Message Dispatching)**
   - 根据客户端上行网络包头的 `MsgId` 或动态绑定的 `RouteRules`，将请求自动转发给对应的功能服（例如：发往 Login 验证，或发往 Battle 请求移动），同时将收到的下行封包准确投送回给客户端。

4. **长连接维持广播**
   - 它在客户端和后端的短生命周期进程中维系了用户稳定的物理连接，使得游戏实现高效率并发和数据帧广播时不被网络断线中断。
