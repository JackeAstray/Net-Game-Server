# DB 数据库代理服务器

`DB` 服务主要针对所有的数据库相关存储或第三方缓存机制进行隔离和代理交互操作。让业务层只需关心抽象的逻辑，把底层 IO/SQL 语句留给负责缓存控制的代理层。

## 核心职责
- **数据存取与同步隔离**: 把关于玩家资料、游戏账单信息、离线任务等数据记录与更新的操作包裹于 DB 所曝露的自定协议中。
- **全局标识分发**: 管理各种依赖于递增 ID 的核心数据（像角色全局唯一 ID（UID）等）。例如 `Login` 服务器初次连接完毕通过报文触发请求，`DB` 向其回答自减后的当前库已占用的最高序列码进行后续生成工作同步。
- **连接池管理**: 管理后端诸如 MySQL，Redis 或者 MongoDB 等真实媒介连接字符串。通过自身集群连接池保护防止流量过大致使慢查询从而造成服务端整个宕机。

## 交互模式
其余的内部微服务通过 TCP 指令格式打包请求指令，然后扔带入诸如 `[RequestId(8)][MsgId(4)][Data]`，当 DB 写入库中或从库中读取完毕后再进行序列化返回。
