# Center 中心服务器

`Center` 服务器作为微服务集群的**控制枢纽**与**协调器**，起到统一管理全局系统状态和进行部分顶层业务分配的作用。

## 场景与功能
- **服务发现于注册**: 当其它服务器节点启机时（如 `Game`、`Battle` 甚至具体的地图进程节点），它们会尝试与 `Center` 取得联系，并将自身的地址、负载情况、负责区服等元信息上报其注册中心册，这样以便网络请求需要打跨服时知道各机器在哪。
- **跨服业务协调 (Cross-Server Coordination)**: 处理诸如世界匹配、公会排位跨服宣战等不只是依附于单颗 `Game` 节点身上的全集群状态逻辑。它像是一个高级调度长。
- **广播和配置下发**: 用以当配置发生热更时可以通过 `Center` 统一向全局的存活服务下达指令刷新。

## 架构注意
通常全集群全局部署单一 `Center` 或者少量高可用多开节点主从备份构成。一旦崩溃，可能造成诸如跨服匹配中断以及新节点上线系统无法感知等情况。因此在日常扩展开发中要保持高可用性和低负载逻辑设计。
