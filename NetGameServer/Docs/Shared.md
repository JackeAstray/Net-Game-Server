# Shared 共享基础库

`Shared` 项目不直接产出独立服务进程，主要用于沉淀跨服务复用的公共模型、协议常量与基础工具能力。

## 主要内容
1. **Config**：统一配置模型与配置加载工具（如 `ConfigHelper`）。
2. **Messages**：消息体定义、协议模型与 `MessageIds` 常量集合。
3. **Logger**：统一日志接口与日志落地能力。
4. **UID Generator**：全局唯一标识生成与相关辅助逻辑。
5. **Serialization**：统一序列化能力封装（如 `Shared.Json`）。

## 设计目标
- 避免重复实现与跨项目拷贝。
- 保证协议、模型与基础工具的一致性。
- 降低服务间协作成本，提升可维护性。
