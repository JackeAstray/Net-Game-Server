# Shared 共享基础库

`Shared` 项目本身不产生可执行进程（非单一服务器实体），它的存在是提供全项目共享代码逻辑存放空间，以此来控制所有的分布式模块互相复用公共结构，避免冗杂的拷贝与不一致维护。

## 涉及范围包含：
1. **Config**: 基于全局所拥有的所有项目统一的配置文件类模型和加载解析工具 (`ConfigHelper`)。
2. **Messages**: 所有协议栈交互的数据包体协议类模型及对应关系映射类汇总。
3. **Logger (日志工具)**: 确保所有不同模块通过同一日志机制向文件系统以及远端系统回溯运行状况以做到调试及预警查阅。
4. **UID Generator**: 分布式主键发生逻辑等统一全局计算生成类算法模块。
5. **Serialization**: 基于 `JSON` 或者自有的序列化操作的格式化公共执行文件存放位置（例如使用统一重写扩展来优化默认 Json 解析器大小和速度的包裹类库）。
