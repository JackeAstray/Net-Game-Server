# Game 通用逻辑服务器

`Game` 服务承载大多数核心玩法逻辑，是单服或分区场景中的主要业务执行节点。

## 主要职责
- **玩家会话与角色状态管理**：在线状态、角色内存模型、状态同步。
- **系统玩法处理**：背包、任务、商城、社交、公会等常规业务逻辑。
- **非高实时战斗逻辑**：常规 PvE、数值结算与流程驱动。
- **业务响应回包**：处理来自 `Gateway` 的客户端请求并返回结果。

## 协作关系
- `Gateway`：负责接入层连接、协议解析与消息路由。
- `DB`：负责数据持久化与查询。
- `Center`：参与跨服协调、调度与全局状态协同。
- `Battle`：高实时战斗由战斗服承接，`Game` 负责外围业务联动。

## 扩展策略
- 通过多实例横向扩展提升吞吐。
- 按场景、分区或业务模块做节点分工。
- 保持逻辑层与存储层解耦，便于独立扩缩容。
