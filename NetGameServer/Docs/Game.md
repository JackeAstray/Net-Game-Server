# Game 通用逻辑服务器

`Game` 服务器执行核心的游戏内系统玩法逻辑运算。它是单服/单区中最主要的运算部分。

## 处理能力边界
它通常负责（但不限于）：

- **玩家信息存储**: 比如玩家进入服务器之后的角色内存实体构建加载与同步缓存。
- **背包系统**: 道具捡取，装备强化，金币及资源交易增减逻辑处理与合法性校验。
- **任务公会**: 每日任务触发，任务完成校验以及奖励结算；聊天广播，公会信息拉取等社会行为计算分发。
- **常规 PvE**: 非即时同步或者不需要强物理判定的伤害数字推演，血量的加减扣除。

## 特点
`Game` 内部会频繁触发数据层 `DB` 请求以用来归档信息持久化。外部玩家的绝大部分基础互动报文（例：比如购买商城，获取排位面板）都会在 `Gateway` 层经过拆分路由进入 `Game` 所在的频道线程处理，返回数据发下并展示到相应渲染。

为扩展容载，不同于 `Login` 或者 `Center`，一个集群（比如一个物理机群）里面通常包含多个 `Game` 节点并行分散处理不同场景或区域的用户压力。
