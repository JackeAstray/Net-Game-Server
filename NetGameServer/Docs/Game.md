# Game 服务器 (通用业务逻辑模块)

## 概述
Game 服务（有时称作 Logic 服务）处理所有不需要实时同步战斗的、通常容忍轻微延迟的通用网络游戏系统逻辑。它是大部分常规系统和日常玩法业务流的归宿。

## 核心职责

1. **角色常规功能**
   - 背包系统、物品使用、强化、装备打造等资源核算。
   
2. **社交网络与经济系统**
   - 聊天频道通信分发、公会（帮派）的成员管理和公会建设、邮件收发存储。
   - 拍卖行或交易系统的处理，保证经济交易的数据强一致性（通过事务更新 DB）。

3. **目标机制管理**
   - 成就系统判定、任务进度与主支线剧情节点管理。

4. **对战大厅准备室**
   - PvE 或 PvP 前的大厅驻留状态维护（例如排队中的玩家天赋切换、商城购买行为也是由它在此阶段接管处理的）。

## 交互特点
由于 Game 节点往往存储了玩家角色的通用养成数据，它在运作时经常需要与 DB 服务器发生高频数据交换，并将缓存数据同步进数据库，确保用户下线不丢失状态。
